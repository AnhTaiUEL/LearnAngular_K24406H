## 💻 HƯỚNG DẪN CHẠY ỨNG DỤNG (HOW TO RUN)

1. Cài đặt các gói thư viện:
   ```bash
   npm install
   ```
2. Khởi chạy ứng dụng Angular Server:
   ```bash
   npm start
   ```
3. Mở trình duyệt web truy cập: `http://localhost:4200/`.
4. Trên thanh Menu xổ xuống đầu trang, chọn **Chapter 3** $\rightarrow$ bấm vào bài cần xem (**Bài 13**, **Bài 14**, hoặc **Bài 18**).
